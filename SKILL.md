# FLOW 1-Page Decision Card Skill
1. Ask the founder: "Which single recurring decision still waits for you every week?"
2. Record baseline: weekly approvals, escalations/100 decisions, founder minutes/week, rework %.
3. Define 1 routine owner (agent or teammate) + 3 binary green-light rules.
4. Run offline shadow test on 15-20 past requests (target: 0 bad approvals).
5. Enforce 1-line escalation format: `[Decision needed] | [Recommendation] | [Rule breached]`.
